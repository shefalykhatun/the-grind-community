# The Grind — Web3 Gaming Community Website

A responsive, anime-inspired Web3 gaming community landing page.

## Files
- `index.html` — page structure
- `style.css` — responsive neon / cyberpunk styling
- `script.js` — community links, collaboration cards, giveaway, founder and community posts
- `anime-hero.jpg` — generated anime gaming character artwork

## Customize before publishing
Open `script.js` and update:
1. `SITE_CONFIG.xProfileUrl` with your real X profile.
2. `SITE_CONFIG.giveawayPostUrl` with your current giveaway post.
3. The `collaborations` list with your real project names, status, descriptions and links.
4. `founderPosts` and `communityPosts` with real posts.

Replace every demo `https://x.com/` URL. Do not leave demo links on the live site.

## Publish
Upload the contents of this folder to your GitHub repository. If using Netlify, connect the repository and set the publish directory to the folder containing `index.html` (or use the repository root if these files are at the root).
