# The Grind Community Website

A simple static starter website for a community hub.

## Files
- `index.html` — page structure
- `style.css` — visual design
- `script.js` — sample collaborations, giveaway link and post previews

## Customize
Open `script.js` and replace the demo links/text in `SITE_CONFIG`, `collaborations`, `founderPosts`, and `communityPosts`.

Note: this starter does not automatically fetch posts from X. Automatic X feed syncing needs a suitable X API/app integration and usually a backend.
